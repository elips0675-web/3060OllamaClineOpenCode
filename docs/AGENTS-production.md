# Production: что значит «готово» и pre-flight перед закрытием блока

> Перенесено из SwiftMatch (`docs/AGENTS-production.md`), но в редакции комплекта.
> Там DoD — про Docker, nginx, миграции и прод-`.env`; здесь этих сущностей нет.
> Механизм тот же: **готово — это доказанная команда, а не созданный файл.**

## Golden Rule: готово ≠ файл создан

Если блок звучит как «добавить скрипт / правило / запись в журнал», Definition of
Done — не `git commit` и не новый файл в дереве, а **проверенный рабочий флоу**:
команда запускается, гейт падает на сломанном входе, число в документе совпадает с
выводом терминала. Всё, что не проверено командой, пишется словами «не проверено»
— и тогда это честный статус, а не готовность.

| Создано | Не значит «готово» |
|---|---|
| `scripts/*.mjs` | Команда запускается из корня, exit 0 на целом входе **и** exit ≠ 0 на сломанном. Гейт, который не краснеет, — декорация (`README.md`, раздел «Гейты») |
| `scripts/*.test.mjs` | Файл добавлен в строку `test` в `package.json`. Тест, которого нет в этой строке, не запускается никогда — а `npm.cmd test` при этом зелёный |
| `Modelfile-*` | `ollama ps` показывает **100% GPU**, `03-Замер-скорости.bat` даёт 25–35 ток/с, `eval:live` проходит без таймаутов. Файл сборки ничего не говорит о том, что модель влезла в 12 ГБ |
| Правило в `.clinerules` | `npm.cmd run eval:score --strict` до и после правки: число pass не упало, «выдумано» = 0; сам прогон — `eval:live` (read-only, 7 задач из 10) или ручной по `evals/manual-run.md`. Иначе правка правил — вкусовая, а не улучшение |
| Снимок `test/0X-*.txt` | `node test/build-pack.mjs --check` — **exit 0 в LF-копии**. В клоне с CRLF он красный по построению (`AGT-22`): красный там ничего не доказывает, зелёный — тоже |
| Пункт в `Что доделать.txt` | `npm.cmd run check:backlog` — exit 0; дата «ЗАКРЫТО» встречается в журнале; под закрытым заголовком нет тела. Закрывать только `backlog.mjs close`, а не правкой руками |
| Запись в `Что сделано.txt` | Пять полей заполнены фактами (не «сделано»), в «Проверках» — вывод и код возврата, дата в шапке блока совпадает с датой в заголовке |
| Отчёт прогона `evals/results.json` | Числа совпадают с `npm.cmd run eval:score --strict`, а не с пересказом в `README.md`. Пересказ чужой оценки воспроизводит её числа, включая устаревшие |
| Число тестов в документации | Совпадает с выводом `npm.cmd test`. Счётчик протухает молча: `README.md` держал 217 при фактических 261, пока его не переписали в блоке `DOC-05` (31.10.2026) |
| Карточка из `next-task.mjs` | В разделе «ГЕЙТЫ» только команды, существующие в `package.json` (фильтр `gatesFor`), и путь того проекта, а не чужой хардкод. Иначе агент получает `eslint`, `typecheck` и `check:docs`, которых здесь нет |
| «Работает» в ответе модели | Воспроизведено человеком командой. Ответ локальной 14B — гипотеза; доказательство только в выводе терминала и в `file:line` |

## Pre-flight Checklist (перед закрытием блока)

Проверить **все** пять пунктов, даже если блок казался «только про текст»:

### 1. Правка легла в правильный слой

- Правило — в `docs/AGENTS-*.md` или `.clinerules`; состояние (что сделано, что
  осталось) — только в `Что сделано.txt` / `Что доделать.txt`.
- Новое правило не продублировано в третьем файле: одно правило — один файл,
  остальные ссылаются (`docs/README.md`, «Гигиена»).
- Закрытый пункт переехал в журнал: в бэклоге осталась одна строка ✅ без тела.

### 2. Гейты зелёные

```bat
npm.cmd test
npm.cmd run check:backlog
node test/build-pack.mjs --check
npm.cmd run retent:check
```

Четыре команды, четыре нуля. Ненулевой код — не «мелочь»: `check:backlog` ловит
закрытие без даты в журнале, `--check` — устаревший снимок, `retent:check` —
незакоммиченное окно сверх 6 файлов / 300 строк.

### 3. Ломка доказана, а не заявлена

Для нового или изменённого гейта: сломать вход (испортить снимок, убрать `⏳`,
добавить семь untracked-файлов) и увидеть **exit ≠ 0**; затем восстановить и
увидеть 0. Гейт, который зелёный в обоих случаях, проверяет «ничего» — это тот же
класс, что `build-pack --check` в клоне с CRLF (`AGT-22`).

### 4. Числа и ссылки сверены с фактом

- Каждое число в документе получено командой в этом же блоке, а не перепечатано
  из прошлой записи.
- Каждая ссылка `file:line` открыта: файл существует, строка содержит то, о чём
  говорит текст. Пункт бэклога без цитаты не принимается.
- Утверждение «тест это покрывает» проверяется запуском этого файла, а не
  наличием имени в списке.

### 5. Чекпойнт сделан

- Запись в журнале сверху, дата совпадает с реальной.
- `git add` поимённо (не `git add .`), `git commit --no-verify -F <файл>`, push.
- Копия изменённых файлов и снимков `test/` в `D:\ИИ агент\3060 16 gb` — sha256
  сверить; в клоне `npm.cmd run retent:check` = 0.
- Временные файлы проверок (`tmp/*.txt`, пробные untracked) удалены.

## Чего в комплекте нет

Чтобы не тащить в DoD лишнее: здесь нет БД, миграций, nginx, Docker, деплоя,
секретов и прод-`.env`. Пункты SwiftMatch про дрейф схемы, периметр портов,
healthcheck контейнера и откат релиза к этому комплекту не применимы — их место в
правилах того проекта, а не здесь.
