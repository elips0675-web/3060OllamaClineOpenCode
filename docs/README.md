# Документация комплекта

> Здесь лежат только правила и процедуры. Состояние работы — в
> `Что сделано.txt` и `Что доделать.txt`, доказательства — только в исходном
> коде проекта.

## Не канон

- `Что сделано.txt` — хроника закрытий. Это состояние, а не правило.
- `Что доделать.txt` — открытые пункты. Это очередь, а не правило.
- `Анализ ИИ.md` — разбор внешних материалов, план и честные границы. Это
  решение, а не инструкция.
- `Обучение ИИ.md` — исследовательский материал: идеи и альтернативные
  инструменты, не инструкции комплекта.
- `Анализ ИИ агентов.md` — дамп диалога про харнессы (agentkai, Iridium,
  AgenticSeek, MCP) и сверка с фактами комплекта; часть чисел без источника.
- `docs/archive/` — исходные `.txt` этих трёх разборов (срез 31.10.2026,
  перенесены 31.10.2026). Только история: факты о коде агент берёт из кода, а
  не отсюда. Нумерация строк в `.txt` сдвинута шапкой архива.
- `backups/`, `coverage/`, `logs/`, `test-analysis/`, `vitest-*.json` — данные
  прошлых прогонов. Для агента это не источник фактов о коде.

## Гигиена

- Одно правило — один файл. Не копировать блоки между `.md`, а ссылаться.
- Новые правила не добавлять в корневые `.txt`: там только состояние.
- Если файл не упомянут в `README.md`, `00-ЧИТАЙ-ПЕРВЫМ.txt` или здесь, он
  считается архивом.
- Устаревший документ не удалять молча: перенести в `docs/archive/` и указать
  дату среза.
