# user_preferences — как человек хочет получать работу

> 5–10 строк. Стабильные предпочтения, а не история задач.

- Язык ответа — русский; код, имена и коммиты — по конвенции проекта.
- Формат ответа: вывод → факты `file:line` → что не проверено → следующий шаг.
- Одна правка за шаг, минимальный дифф; без «заодно» рефакторинга.
- Не пересказывать прочитанные файлы обратно в ответ.
- Запрещены `any`, `as any`, `@ts-ignore` и комментарии в коде.
- `git add/commit/push` делает человек: агент показывает дифф, гейты и файлы.
- Если не уверен — задать один вопрос, а не править наугад.
