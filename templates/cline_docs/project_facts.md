# project_facts — постоянные факты проекта

> 5–10 строк. Только то, что не меняется от задачи к задаче.
> Временное состояние — в `activeContext.md`, история — в `progress.md`.

- Порты: фронт 3002, API 8081.
- На Windows пакетный менеджер — `npm.cmd` / `npx.cmd`, не `npm`.
- Основная модель: `swiftmatch-coder-14b:latest`, ctx 12288, 100% GPU.
- `any` / `as any` / `@ts-ignore` запрещены; `unknown` + type guard.
- UI-тексты — только через `t()`, без русского текста в разметке.
- Один пункт бэклога = одна карточка = один файл за подход.
- Секреты (`.env`, ключи, токены) не уходят в облако и не коммитятся.
- Коммит и push делает человек, не агент.
