Главная мысль: локальная модель и все инструменты разработки работают без сети,
но СКАЧАТЬ их надо заранее. После шагов ниже интернет нужен только для облачных
моделей (05-Облако-и-DeepSeek.txt) и для установки новых npm-пакетов.

--------------------------------------------------------------------------------
1. МОДЕЛИ OLLAMA (главный объём)
--------------------------------------------------------------------------------
Скачивается скриптом 02-Установить-локально.bat либо вручную:

    ollama pull qwen2.5-coder:14b                  ~9.0 ГБ   (профиль A, ваша карта)
    ollama pull qwen2.5-coder:1.5b                 ~1.0 ГБ   (автодополнение, живёт рядом)
    ollama pull qwen2.5-coder:7b-instruct-q8_0     ~7.6 ГБ   (только если нужен профиль C)

Для вашей конфигурации (12 ГБ VRAM + 16 ГБ ОЗУ) достаточно первых двух: 9 + 1 = 10 ГБ
видеопамяти, ОЗУ не расходуется на модель.

Место: диск D: (187 ГБ свободно — с запасом).

Где лежат скачанные модели (для бэкапа, чтобы не качать заново):

    %USERPROFILE%\.ollama\models

Папку можно скопировать на внешний диск. После переустановки Windows достаточно
вернуть её на место — Ollama увидит модели без повторной загрузки.

Проверка:  ollama list


--------------------------------------------------------------------------------
2. РАСШИРЕНИЯ VS CODE
--------------------------------------------------------------------------------
Ставятся только с интернетом. Устанавливать так (PowerShell или cmd):

    code --install-extension saoudrizwan.claude-dev        Cline (агент)
    code --install-extension Continue.continue             автодополнение
    code --install-extension dbaeumer.vscode-eslint        подсветка ошибок линта
    code --install-extension bradlc.vscode-tailwindcss     классы Tailwind

Уже установлены (не трогать): google.colab, ms-toolsai.jupyter.*

Если VS Code будет переустанавливаться без сети — сохраните VSIX-архивы заранее:

    mkdir "D:\ИИ агент\3060 16 gb\vsix"
    cd "D:\ИИ агент\3060 16 gb\vsix"

    curl -L -o cline.vsix "https://marketplace.visualstudio.com/_apis/public/gallery/publishers/saoudrizwan/vsextensions/claude-dev/latest/vspackage"
    curl -L -o continue.vsix "https://marketplace.visualstudio.com/_apis/public/gallery/publishers/Continue/vsextensions/continue/latest/vspackage"
    curl -L -o eslint.vsix "https://marketplace.visualstudio.com/_apis/public/gallery/publishers/dbaeumer/vsextensions/vscode-eslint/latest/vspackage"

Установка из файла:  code --install-extension "D:\ИИ агент\3060 16 gb\vsix\cline.vsix"


--------------------------------------------------------------------------------
3. ЗАВИСИМОСТИ ПРОЕКТА (node_modules)
--------------------------------------------------------------------------------
Сборка, тесты и гейты SwiftMatch работают офлайн, ЕСЛИ node_modules уже стоят.
Правило: не удалять их и не запускать npm ci «на всякий случай».

Порядок (один раз, при ОСТАНОВЛЕННОМ стеке — иначе EPERM и полусломанное дерево):

    остановить API на 3002
    cd D:\swiftmatch1bdnoutprodpart1
    npm install
    cd server
    npm install

После этого офлайн работают: npm test, npm run typecheck, npx vite build,
npm run check:docs / check:mirrors / check:n-plus-one и остальные гейты.

Бэкап дерева (чтобы не ставить заново после сбоя):

    tar.exe -a -c -f "D:\ИИ агент\3060 16 gb\node_modules-backup.zip" -C "D:\swiftmatch1bdnoutprodpart1" node_modules
    tar.exe -a -c -f "D:\ИИ агент\3060 16 gb\server-node_modules-backup.zip" -C "D:\swiftmatch1bdnoutprodpart1\server" node_modules

Отдельно: npx/dlx-команды (например npx prettier) без сети не запустятся, если
пакет не лежит в кеше %LocalAppData%\npm-cache. Кеш тоже можно сохранить.

4. БРАУЗЕРЫ PLAYWRIGHT (E2E)
--------------------------------------------------------------------------------
Один раз с сетью:

    npx playwright install chromium

Лежат в %LOCALAPPDATA%\ms-playwright. Без них npm run test:e2e офлайн не пойдёт.

--------------------------------------------------------------------------------
8. КАК ГАРАНТИРОВАТЬ, ЧТО КОД НЕ УХОДИТ В ОБЛАКО
--------------------------------------------------------------------------------
1. В Cline выберите провайдера Ollama и Base URL http://localhost:11434.
   Никаких OpenRouter/Anthropic/OpenAI профилей не включать.
2. Если раньше входили в Ollama Cloud — выполните:  ollama signout
3. В приложении Ollama: Settings -> отключить облачные функции.
4. Проверка: отключите Wi-Fi/кабель, дайте Cline задачу «прочитай файл X».
   Ответил — значит работа идёт полностью локально.
5. В проекте ключи живут только в .env (он в .gitignore). Ключи в переписку
   с агентом и в файлы правил не вставлять.
