# 3060 Ollama · Cline · OpenCode

> Offline coding-agent kit for **RTX 3060 12 GB / 16 GB RAM**: Ollama + Qwen2.5-Coder, Cline / Continue / OpenCode,
> deterministic task selection from a Markdown backlog, and a **local-vs-cloud router** (`local` → 3060, `cloud` → `/next-cloud`).

Комплект для локального ИИ-агента на одной видеокарте: без облака, без API-ключей,
с детерминированным выбором задачи. Модель ничего не выбирает сама — она получает
узкую карточку задачи (~5 КБ) и один файл.

## Что внутри

| Файл | Роль |
|---|---|
| `00-ЧИТАЙ-ПЕРВЫМ.txt` | вход: что это, порядок чтения, ограничения железа |
| `01-Как-всё-работает.txt` | схема: модель, редактор, скрипты, что готово и что нет |
| `02-Установить-локально.bat` | установка моделей Ollama (`swiftmatch-coder-14b`, `swiftmatch-coder-tiny`) |
| `03-Замер-скорости.bat` | замер ток/с и проверка `ollama ps` (100 % GPU) |
| `04-Оффлайн-подготовка.txt` | что скачать заранее, если интернета не будет |
| `05-Облако-и-DeepSeek.txt` | облачный маршрут: ключи, очистка логов, `--standalone` |
| `06-Continue-автодополнение.yaml` | автодополнение на 1.5B, чтобы не занимать VRAM у 14B |
| `07-Автовыбор-задач.txt` | `next-task.mjs`: статусы, коды выхода, строка «Маршрут» |
| `08-Куда-писать-команды.txt` | что вводить в cmd / OpenCode / Cline / Continue |
| `09-Памятка.txt` | одна страница: команды, эскалация, типовые поломки |
| `10-Приложения.txt` | Modelfile, `opencode.json`, контракт скрипта |
| `11-Правки-по-оценке.txt` | что принято из внешних ревью, что отклонено и почему |
| `models/Modelfile-*` | свои сборки под 12 ГБ: 14B q4/q6, 7B q8, 1.5B |
| `.clinerules` | правила для Cline: триггер, эскалация, «коммитит человек» |
| `swiftmatch-3060.code-workspace` | рабочее пространство VS Code |
| `Что сделано.txt` / `Что доделать.txt` | журнал и открытые пункты комплекта |

## Быстрый старт

1. `02-Установить-локально.bat` — скачать и собрать модели.
2. `ollama list` — проверить, что обе модели на месте.
3. В OpenCode: `/models` — узнать точный ID локальной сборки (обычно `ollama/<имя>:latest`).
4. Только после этого вписать `model:` в шапку `.opencode/commands/next.md`.
5. `03-Замер-скорости.bat` — убедиться, что модель целиком на GPU.
6. Дальше — `00-ЧИТАЙ-ПЕРВЫМ.txt` и `09-Памятка.txt`.

## Как выбирается задача

Скрипт `next-task.mjs` (живёт в репозитории проекта, здесь описан контракт) читает
`Что доделать.txt`, отбрасывает закрытые, решения и блокеры, и печатает карточку:
один пункт, один файл, гейты, готовый промпт. Строка «Маршрут» печатает решение:

- нет цитаты `file:line` → `cloud`;
- риск-домен (деньги/Stripe, доступ и секреты, схема БД и миграции, деплой и инфраструктура) → `cloud`;
- иначе → `local`, по одному файлу за подход.

Это ключевые слова, а не оценка сложности: последнее слово за человеком.
Автоматического «упало локально → ушло в облако» нет — маршрут задаётся заранее.

## Требования

- Windows 10/11, PowerShell или cmd (в PowerShell — `npm.cmd` / `npx.cmd`).
- NVIDIA RTX 3060 12 ГБ (или ≥ 10 ГБ VRAM), 16 ГБ ОЗУ.
- [Ollama](https://ollama.com), VS Code + Cline/Continue, OpenCode (по желанию).

## Чего здесь нет

- кода проекта SwiftMatch и его истории — только комплект для агента;
- весов моделей (скачиваются скриптом `02`);
- секретов и ключей: всё, что нужно, задаётся локально в переменных среды;
- лицензии: она не выбрана, по умолчанию действует авторское право.
