# AGENTS.md — вход для агента (OpenCode / облако)

Этот файл читается автоматически. Он короткий намеренно: не перечитывай весь
комплект и не дублируй его содержимое в ответе. Полные правила Cline —
`.clinerules`; маршрут и команды — `07-Автовыбор-задач.txt` и
`08-Куда-писать-команды.txt`.

## 1. Что читать

1. Сначала карточку задачи: `node scripts/next-task.mjs --local --out tmp/next-task.txt`
   (или `--id <ID>`), затем `tmp/next-task.txt`.
2. Дальше — только файлы из раздела «СРЕЗ ДЛЯ ОДНОГО ПОДХОДА».
3. Большой файл читать разделом (`grep` + `offset`), не целиком.

Не читать без прямой необходимости:

- `Что сделано.txt` — история закрытий, не рабочий контекст;
- `README.md` и `00-ЧИТАЙ-ПЕРВЫМ.txt` — витрина и установка для человека;
- `11-Правки-по-оценке.txt`, `docs/archive/` — история рецензий;
- `test/` — пакет для внешней рецензии, рабочему агенту не нужен.

## 2. Бюджет запроса

- ≤ 3 файла и ≤ 60 КБ входа на один шаг. Больше — разбить на шаги или отдать
  облаку.
- Один запрос = один вопрос. Не пересказывать прочитанное и не вставлять файлы
  обратно в ответ: это удваивает трафик.
- Если ответ уже есть в карточке, не искать его заново.

## 3. Маршрут «локально / облако»

- 1 файл — локально (14B).
- 2–6 файлов — локально по одному файлу за подход.
- 7+ файлов, SQL/схема, деньги/доступы, красные гейты, тесты на 200+ строк,
  дифф больше 300 строк или дифф в риск-домене — облако.
- Две локальные ошибки подряд — эскалация в облако, а не третья попытка.

## 4. Доказательства

- Факт — только `file:line` из исходного кода.
- `.md`, `.txt`, логи, отчёты, `coverage/`, `test-analysis/`, `vitest-*.json`
  доказательством не являются.
- «Не найдено» — только со списком проверенных файлов.

## 5. Бэклог

- `Что доделать.txt` — только открытые пункты.
- Закрытый пункт удаляется из бэклога целиком; единственная запись — раздел в
  `Что сделано.txt` с ID и датой. Строка `## ✅ … — ЗАКРЫТО` — FAIL гейта.
- Закрывать: `npm.cmd run backlog:close -- --id <ID>`.

## 6. Гейты

Все должны дать exit 0:

```
npm.cmd test
npm.cmd run check:backlog
node test/build-pack.mjs --check
npm.cmd run retent:check
```

Локальная модель не выполняет `git add`, `git commit`, `git push`: коммит
делает человек. Облачная — только по прямому указанию в текущей сессии.

## 7. Секреты

Не отправлять в облако `.env`, ключи, токены и пароли. Не коммитить их.

## 8. Модель

`swiftmatch-coder-14b:latest`, ctx 12288, `ollama ps` = 100% GPU,
~31.8 ток/с. Замер: `03-Замер-скорости.bat`.
