## 1. Главный вывод материала

Проблема «Cline тупой, его надо обучать» — это не выбор инструмента, а
архитектура работы с контекстом. Два принципиально разных пути решения:

| Путь | Кто | Как решает |
|---|---|---|
| Архитектурный | Aider | repo map и агрессивная экономия контекста |
| Инфраструктурный | openclose / Hermes | Skills, Jobs, долговременная память |

«Обучение» ни в одном из инструментов не означает дообучение весов:

| Инструмент | Чем «обучается» |
|---|---|
| Cline | `.clinerules` + Memory Bank |
| Aider | `CONVENTIONS.md` + режим `--architect` |
| openclose | `config.toml` + Skills |
| Hermes | `memory.md` + `user.md` |

## 2. Три сценария выбора

| Сценарий | Инструмент | Команда / настройка | Оговорка |
|---|---|---|---|
| А. Существующий код: рефакторинг, фичи, багфиксы | Aider | `aider --model ollama/qwen2.5-coder:14b` + `CONVENTIONS.md`, `--architect` для сложного | не «обучается», но не теряет контекст |
| Б. Автоматизация: расписание, браузер, уведомления | openclose | `config.toml` + Skills + Jobs | крутая кривая обучения, «настроил и автоматизировал» |
| В. Свой узкий агент | Smolagents | 10 строк кода | для нестандартных задач (SQLite → отчёт → Telegram) |

Чего избегать на 12 ГБ: **Devika** и **OpenHands** как основной инструмент —
высокое и очень высокое потребление VRAM, свопинг в RAM, сильные тормоза.

## 3. Кандидаты в «комбайны» (один инструмент: код + файлы + терминал + браузер + cron + память)

| Инструмент | Что даёт | Оговорка | В комплекте |
|---|---|---|---|
| AgenticSeek | 100% локальная альтернатива Manus: браузинг, код, файлы, мультиагентное планирование | по словам авторов — прототип, на сложном браузинге «проседает» | не ставился |
| Iridium Agent | веб-IDE + терминал + Chromium + мультимодельный движок в одном CLI; чекпоинты, песочница | память — сессионная и чекпоинты, а не долговременная | не ставился |
| Daedalus | движок Hermes: память между сессиями, «сонное» дообучение навыков, Playwright, PyAutoGUI | тяжёлый, амбициозный | не ставился |
| agentkai | один агентный цикл, память в `SOUL.md`/`USER.md`/`MEMORY.md`, cron, локальный дашборд, 12 навыков (Gmail, Calendar, GitHub), шлюзы Telegram/Discord | больше персональный ассистент, чем кодинг-агент | не ставился |
| OpenJarvis | open-source фреймворк, «локально-первый», пресеты агентов, Ollama | данные о происхождении («Stanford») не проверены | не ставился |

Предлагаемый порядок знакомства из материала: Iridium (всё в одном окне) →
AgenticSeek (посмотреть на локальный аналог Manus) → agentkai (если нужна
личная автоматизация).

Главный компромисс тот же, что у Cline: чем больше инструментов хочет модель,
тем важнее дисциплина контекста. «Комбайн» не отменяет 12 ГБ VRAM.

## 4. Сравнение подходов «прокачки» агента

| Метод | Сложность | Нагрузка на RTX 3060 | Качество | Стоимость |
|---|---|---|---|---|
| Бесплатный API DeepSeek (OpenRouter, GitHub Models) | очень низкая | 0% (всё в облаке) | максимальное | $0 в рамках лимитов |
| `.clinerules` + few-shot + RAG (промптинг) | низкая | обычная (память под контекст) | высокое (исчезают «глупые» ошибки) | $0 |
| QLoRA через Unsloth + бесплатный Colab (T4/A100) | высокая | локально 0 | среднее, зависит от датасета | $0 |

Практический совет материала: если хочется «умнее» без облака — сначала
контекстная инженерия. Fine-tune — в Colab через Unsloth, экспорт в GGUF,
возврат на 3060. Локально на 12 ГБ обучать 7B — «путь к мучениям».

## 6. Шесть шагов «из тупенького в предсказуемого» (Cline)

| Шаг | Что делать | Эффект |
|---|---|---|
| 1. Compact Prompts | Cline ⚙ → Features → «Use Compact Prompt» | системный промпт короче примерно на 90%, модель не «не дочитывает» инструкции |
| 2. `.clinerules` | папка `.clinerules/` с тематическими файлами (`01-coding-style.md`, `02-testing.md`, `03-architecture.md`); конкретно, а не абстрактно; ссылки на свои примеры («ошибки — как в `/src/utils/errors.ts`»); блок Confidence Check 0–10, ниже 7 — вопрос; команда `/newrule` | правила подгружаются в каждую задачу |
| 3. Memory Bank | `.clinerules/memory-bank.md`; `initialize memory bank` в начале, `update memory bank` в конце | память переживает перезапуск сессии |
| 4. `/deep-planning` | для многофайловых и архитектурных задач: исследование → вопросы → `implementation_plan.md` → утверждение → код | меньше переделок |
| 5. MCP-серверы | MCP Marketplace в Cline, «более 200 серверов»; добавлять под конкретную нехватку, не всё сразу | доступ к БД, браузеру, поиску, git |
| 6. Model Orchestration | лёгкая модель — суммаризация, форматирование, простые правки; мощная — планирование (`--thinking high`) и рефакторинг; 7B для рутины, 14B для планирования | не заставлять одну модель делать всё |

**Бесплатные MCP-серверы по типу «бесплатности»**

| Сервер | Тип | Ограничение |
|---|---|---|
| DuckDuckGo MCP | open source, без ключа | нет |
| Tavily MCP | freemium | 1000 кредитов/мес, карта не нужна |
| Firecrawl MCP | freemium | 1000 кредитов/мес |
| Brave Search MCP | freemium | уровень доступа к API Brave |
| Safe-agent-mcp | MIT, локально | аудит ключей и идемпотентности, без сети |
| Unbrowse | freemium | может требовать ключ даже на бесплатном тарифе |

## 7. Железо: что важно именно для 3060

| Параметр | Значение из материала | Факт комплекта |
|---|---|---|
| Сладкая точка | 14–16B в Q4_K_M / Q5_K_M (GGUF) | 14B q4_K_M — профиль `local` |
| VRAM модели | ~8.5 ГБ (Q4_K_M), остаётся ~3.5 ГБ на контекст | `models/Modelfile-14b-q4`: ~9.0 ГБ + ~1.1 ГБ KV = ~10.1 ГБ при `num_ctx 12288` |
| Контекст | 8K–16K токенов без OOM | 12288 (профиль A), 16384 (профиль B), 8192 — аварийный шаг при split |
| Для 6 ГБ VRAM | Qwen2.5-Coder-7B Q4_K_M (~5 ГБ) или Llama-3.2-3B | профили `local7` / `local-q5` |
| 32B+ в Q2/Q3 | часть слоёв уходит в RAM, 30 → 2–3 tok/s | не используется |

Modelfile из материала против комплекта:

| Параметр | Материал | `models/Modelfile-14b-q4` |
|---|---|---|
| `FROM` | `qwen2.5-coder:14b` | `qwen2.5-coder:14b` |
| `num_ctx` | 8192 | **12288** |
| `num_gpu` | 999 | 99 |
| `temperature` | 0.2 | 0.2 |
| `top_p` | 0.9 | 0.9 |

Почему `num_ctx` задаётся явно: без него Ollama может попытаться выделить
память под 32K+, что на 12 ГБ даёт падение драйвера или троттлинг.

Параметры генерации в Cline: temperature 0.1–0.3, max tokens 2048–4096,
stop sequences (в исходнике раздел обрывается).
