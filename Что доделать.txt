# Что доделать — комплект «3060 16 GB» (01.11.2026)

> Как читать: ID = код секции + номер (`BLK-01`, `RUN-02`) — стабильный, при
> вставках не переиспользуется. Статусы: `⏳ (проверено ДД.ММ.ГГГГ)` — открыто и
> факт перепроверен; `⏳ (blocked: причина)` — ждёт внешнего; `⏳ (decision)` —
> ждёт решения владельца; `⏳ (watch)` — не делать сейчас. У открытого пункта
> обязательна дата проверки. Гейт: `npm.cmd run check:backlog`.
>
> **Бэклог ≠ история.** Закрытый пункт здесь НЕ остаётся: он удаляется, а
> единственная запись — в «Что сделано.txt». Строк `## ✅ … — ЗАКРЫТО` здесь
> быть не должно; гейт считает их нарушением. Правила — в конце файла.

## Правила работы с журналами и бэклогом

- **Бэклог ≠ история.** Как в SwiftMatch (`docs/AGENTS-workflow.md:333,336`):
  закрытый пункт удаляется из бэклога **целиком** — без строки ✅, без тела и
  без «остаточных» упоминаний. Единственная запись о закрытии — раздел в
  «Что сделано.txt» с ID и датой. Строка `## ✅ … — ЗАКРЫТО` — FAIL
  (`npm.cmd run check:backlog`).
- **Закрывать инструментом.** `node scripts/backlog.mjs close --id BLK-01`
  удаляет секцию и откажется закрывать, если в журнале нет ID пункта или даты.
- **Открытый пункт — с ID и датой.** Формат: `### PREFIX-NN — заголовок`,
  внутри `Факт: …` и `Статус: ⏳ (проверено ДД.ММ.ГГГГ)`. Пункт без ID не
  выбирается скриптом и не считается пунктом.
- **Пункт без цитаты не принимается.** Факт — только `file:line`, открытый и
  проверенный по коду; пересказ чужой оценки без чтения файла — не факт.
- **Один канон.** `npm.cmd run check:backlog` проверяет ID, статусы, даты и
  отсутствие закрытых строк. Перед коммитом — прогнать.
- **Кодировка и правки.** `.txt`-журналы и бэклог править node-скриптами
  (`split(/\r?\n/)`, join с тем же EOL), не PowerShell: он ломает кириллицу и
  кавычки. После правки — прочитать файл и прогнать гейт.
- **Чекпойнт после каждого блока.** Микроблок → тесты/гейты → запись в «Что
  сделано.txt» → `git add` поимённо → `git commit` → `git push origin main`.
