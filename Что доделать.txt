## Принятые решения — не делать

- Автопереход «локальная ошиблась → само ушло в облако». Cline и Ollama не
  знают про OpenCode; правило эскалации живёт в `.clinerules` п.11 и работает
  только через человека.
- Автокоммит моделью. Коммит и push делает человек (`.clinerules` 11.1);
  `stage:checkpoint` запускает тоже человек.
- 100% покрытие, mutation testing, visual regression — для соло-проекта цена
  выше пользы (решение владельца, 11 раздел 3).
- Строка `model` в `next.md` «на всякий случай», без проверки ID в `/models`.
- Второй экземпляр правил: комплект не копирует `AGENTS.md`, а держит
  `.clinerules` копией проектного (синхронизирован 30.10.2026) и ссылается на
  `AGENTS.md`. Правки правил вносятся в проект, в комплект переносится копия.

## Правила работы с журналами и бэклогом

- **Бэклог ≠ история.** Закрытый пункт уходит из бэклога в «Что сделано.txt»;
  здесь остаётся одна компактная строка ✅ со ссылкой на журнал. Тело под
  закрытым заголовком — FAIL (`npm.cmd run check:backlog`). Дата «ЗАКРЫТО
  ДД.ММ.ГГГГ» обязана встречаться в журнале, иначе это «молчаливое удаление».
- **Закрывать инструментом.** `node scripts/backlog.mjs close --id BLK-01 --ref
  "раздел …"` сам откажется закрывать, если даты ещё нет в журнале.
- **Открытый пункт — с ID и датой.** Формат: `### PREFIX-NN — заголовок`,
  внутри `Факт: …` и `Статус: ⏳ (проверено ДД.ММ.ГГГГ)`. Пункт без ID не
  выбирается скриптом и не считается пунктом.
- **Пункт без цитаты не принимается.** Факт — только `file:line`, открытый и
  проверенный по коду; пересказ чужой оценки без чтения файла — не факт.
- **Один канон.** `npm.cmd run check:backlog` проверяет ID, статусы, даты,
  отсутствие «надгробий» и сверку дат с журналом. Перед коммитом — прогнать.
- **Кодировка и правки.** `.txt`-журналы и бэклог править node-скриптами
  (`split(/\r?\n/)`, join с тем же EOL), не PowerShell: он ломает кириллицу и
  кавычки. После правки — прочитать файл и прогнать гейт.
- **Чекпойнт после каждого блока.** Микроблок → тесты/гейты → запись в «Что
  сделано.txt» → `git add` поимённо → `git commit` → `git push origin main`.
