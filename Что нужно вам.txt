Что нужно вам (GUI/человек)
1. BLK-05 — проверить Tab (1 минута)
1. Открыть VS Code
2. Дождаться загрузки Continue (иконка в статус-баре)
3. Открыть .js/.ts файл, поставить курсор в тело функции
4. Нажать Tab — должна появиться подсказка
5. Записать: пришла / не пришла, сколько времени
6. Ввести текст — проверить debounce (пауза ~300 мс)
2. RUN-04 — проверить /next в TUI (2 минуты)

1. Открыть OpenCode TUI (opencode из корня комплекта)
2. Набрать / — должен появиться список команд с /next и /next-cloud
3. Выбрать /next — должна напечататься карточка из next-task.txt
4. Проверить: какая модель отвечает? (должна быть swiftmatch-coder-14b)
5. Выйти из TUI
3. AI-01 — переключить модели в Cline (3 минуты)

1. Закрыть VS Code
2. switch-ai.bat local-q5 (из корня проекта)
3. Открыть VS Code → Cline → шестерёнка → API Configuration
4. Проверить: Model = swiftmatch-coder-7b-q5, Context = 16384
5. Закрыть VS Code → switch-ai.bat local → открыть VS Code — проверить
6. Закрыть VS Code → switch-ai.bat cloud → открыть VS Code — проверить
7. Записать результат в 12-Переключение-моделей.txt (раздел «Факт с машины»)
4. AGT-02 — прогнать 10 задач (долго, ~2 часа)

1. Для каждой задачи из evals/tasks.json:
   - Новая сессия Cline
   - Скопировать prompt задачи
   - После ответа: node scripts/agent-eval.mjs record --id E-XX --pass/fail --steps N --fabricated N
2. npm run eval:score -- --strict
3. Записать результат в «Что сделано.txt»
