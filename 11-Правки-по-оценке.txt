  8.1 ГЛАВНОЕ. «Ollama локально» и «OpenCode» — не альтернатива друг другу.
      Это два независимых вопроса:
        • НА ЧЁМ считать: локальная модель на 3060 или облачная. Только это
          и решает скрипт (local / cloud);
        • ЧЕМ исполнять: Cline в VS Code, Continue (автодополнение) или
          OpenCode в терминале. OpenCode работает и на локальной Ollama —
          он сам находит её на 127.0.0.1:11434 и показывает модели как
          ollama/<имя> (08, п.3.6). Cline точно так же можно направить
          в облако ключом DeepSeek.
      Отсюда практический вывод: держать две обвязки (Cline для локали,
      OpenCode для облака) не обязательно. Можно работать в одной, меняя
      только модель сессии или шапку команды.

  8.2 ЧТО УСИЛЕНО В КОДЕ. Раньше routeFor смотрел ровно один признак —
      число файлов; из-за этого «добавить миграцию в одном файле» уходило
      на 3060. Теперь решение принимается по трём признакам в порядке
      приоритета:
        1) нет цитаты file:line                    -> cloud (правило проекта);
        2) риск-домен в тексте пункта или пути файла -> cloud;
        3) иначе                                   -> local, по одному файлу.
      Риск-домены: money (платежи, Stripe, подписка, возврат, выплата,
      комиссия), access (JWT, auth, CSRF, adminAuth, секрет, токен,
      уязвимость, IDOR, rate-limit, пароль, XSS, SQL-инъекция), schema
      (миграция, mysql_schema, ALTER/CREATE TABLE, ENUM, CHECK, индекс),
      infra (docker, compose, deploy.yml, nginx, деплой, kubernetes).
      Причина в карточке печатается явно: «облако (/next-cloud): <домен>».
      Это ключевые слова, а не оценка сложности — так и написано в карточке:
      «скрипт смотрит ключевые слова, сложность он не оценивает».

  8.3 НОВЫЕ ФЛАГИ. `--route` печатает только решение одной строкой
      (`local<TAB>текст` / `cloud<TAB>текст`) и не печатает карточку —
      удобно для скриптов и для быстрой проверки «куда уйдёт задача».
      `--local` теперь фильтрует через routeFor, то есть не выдаёт пункты
      риск-домена (раньше проверялась только цитата). В `--json` добавлено
      поле route = { target, reason, text }, reason — одно из no-citation /
      money / access / schema / infra / single-file / stepwise.

  8.4 ЧЕСТНО О ГРАНИЦАХ. Ложные срабатывания возможны в обе стороны:
      слово «токен» в тексте отправит задачу в облако, а тяжёлый
      рефакторинг без таких слов останется локальным. Скрипт не читает код.
      Автоматического «упало локально — ушло в облако» по-прежнему нет:
      маршрут печатается, запуск модели делает человек (07, п.6.7–6.8).
